KEY FINDINGS
================================================================================

1. CLAUDE CODE SKILLS AVAILABLE
   - Official Skills Repository: github.com/anthropics/skills
   - Available categories:
     * Creative & Design (p5.js, Canvas, SVG generation)
     * Development & Technical (Artifacts builder, MCP creation, Web testing)
     * Enterprise (Brand guidelines, Internal comms, Theme factory)
     * Document Processing (DOCX, PDF, PPTX, XLSX manipulation)
   - User can create custom project-scoped and personal-scoped skills
   - Skills auto-discovered based on relevance to user's request

2. CUSTOM SLASH COMMANDS
   - Location: .claude/commands/ (project) or ~/.claude/commands/ (personal)
   - Features:
     * Arguments support ($ARGUMENTS, $1, $2, etc.)
     * File references (@filepath)
     * Bash execution (!`command`)
     * Frontmatter metadata (allowed-tools, description, model)
     * Namespacing via subdirectories
   - 148+ professional commands available in Claude Command Suite
   - Can reduce token usage by ~20%

3. MCP (MODEL CONTEXT PROTOCOL) SERVERS
   - 300+ servers available at github.com/modelcontextprotocol/servers
   - Transport types: HTTP, SSE, stdio
   - Setup scopes: user (personal), project (shared), local (experimental)
   - Popular servers for development:
     * GitHub - PR/issue management
     * Playwright - Browser automation & testing
     * Figma - Design system integration
     * Sentry - Error monitoring
     * Vercel - Deployment management
     * Linear/Jira - Issue tracking
     * Notion - Documentation
   - Authenticated with OAuth 2.0 via /mcp command

4. AGENT SKILLS ARCHITECTURE
   - Model-invoked (auto-discovered) vs user-invoked (slash commands)
   - Structure: SKILL.md + supporting files (docs, scripts, templates)
   - Locations: ~/.claude/skills/ (personal) or .claude/skills/ (project)
   - Git-shareable with team
   - Tool permissions: allowed-tools frontmatter field
   - Best practices: keep focused, specific descriptions, test with team

5. CLAUDE CODE PLUGINS
   - Packaged extensions with commands + skills + MCP servers
   - Available on multiple marketplaces (229+ plugins documented)
   - Can be distributed via git or marketplaces
   - Plugin structure: plugin.json + .claude/ directory + .mcp.json

MCP SERVERS TO CONFIGURE
================================================================================

CRITICAL FOR ABS:

1. Playwright (user-scoped)
   Command: claude mcp add --transport stdio playwright --scope user -- npx -y @executeautomation/mcp-playwright
   Use: E2E testing, visual regression, accessibility validation in real browsers

2. GitHub (project-scoped)
   Command: claude mcp add --transport http github --scope project https://api.githubcopilot.com/mcp/
   Use: PR management, issue linking, reviewer suggestions

3. Figma (project-scoped)
   Command: claude mcp add --transport http figma --scope project https://mcp.figma.com/mcp
   Use: Design spec reference, token validation, consistency checking

SUPPORTING:

4. Sentry (user-scoped)
   Command: claude mcp add --transport http sentry --scope user https://mcp.sentry.dev/mcp
   Use: Production error monitoring, regression detection

5. Vercel (user-scoped)
   Command: claude mcp add --transport http vercel --scope user https://mcp.vercel.com/
   Use: Deployment management, Storybook hosting
